## 📋 Project Overview

This repository contains a comprehensive usability analysis of the **University of Padua website** (unipd.it), conducted as part of the Web Information Management course at the University of Padua. The analysis evaluates the website's effectiveness in providing a seamless user experience for students, faculty, staff, and visitors.

The study focuses on the desktop version of the Italian website, examining various aspects of usability including navigation, information architecture, visual design, and search functionality.

## 🎯 Objectives

- **Evaluate user experience** for diverse stakeholders (students, faculty, staff, visitors)
- **Analyze information architecture** and content organization
- **Assess navigation efficiency** and website structure
- **Examine visual design** and interface elements
- **Test search functionality** and information retrieval
- **Provide actionable recommendations** for improvement

## 📊 Analysis Framework

The analysis employs the **"6 Ws" framework** (commonly used in journalism) to systematically evaluate each webpage:

- **Where**: User orientation and navigation paths
- **Who**: Site representation and authority
- **Why**: Purpose and value proposition
- **What**: Content offering and user choices
- **When**: Timeliness and currency of information
- **How**: Methods for achieving user goals

## 🔍 Key Areas Analyzed

### Homepage Analysis
- First impression and visual hierarchy
- Content organization and layout
- Navigation elements and user guidance
- Image carousel and interactive elements

### Internal Pages Structure
- "List-of-links" pages functionality
- Normal content pages layout
- Breadcrumb navigation consistency
- Content presentation and formatting

### Website Navigation
- Menu structure and accessibility
- Link visibility and visited states
- Scrolling behavior and page depth
- Mobile-responsive design elements

### Search Functionality
- Search interface and usability
- Results presentation and filtering
- Multi-language content handling
- Chatbot integration and support

## 🔧 Key Findings & Recommendations

### Strengths
- ✅ Strong brand identity and institutional recognition
- ✅ Comprehensive content coverage
- ✅ No data collection requirements for basic navigation
- ✅ Consistent color scheme and branding
- ✅ Functional internal search system

### Areas for Improvement
- ❌ **Information Architecture**: Cluttered homepage with unclear navigation hierarchy
- ❌ **Navigation Consistency**: Inconsistent breadcrumb implementation
- ❌ **Link States**: No visual indication of visited links
- ❌ **Search Filters**: Limited advanced search options
- ❌ **Mobile Optimization**: Suboptimal mobile interface design
- ❌ **Content Depth**: Excessive clicks required to reach specific information
